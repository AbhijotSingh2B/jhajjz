# Jhajj'z — website

New website for Jhajj'z, luxury car and coach rental (Mohali / Chandigarh, since 1998).
Next.js 16 · Tailwind CSS v4 · shadcn/ui on Radix · Motion.

```bash
npm install
npm run dev
```

Client details live in `lib/site.ts`. Project notes, design rules and open items are in `CLAUDE.md`.
